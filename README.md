# Nice Journey prototype

Godot 4.6.2 stable Mono prototype. The Godot project is in [`nicejourney/`](nicejourney/); open that directory in Godot, not the repository root.

The design authority is [`Nice_Journey_Master_Game_Specification_V2_1.md`](Nice_Journey_Master_Game_Specification_V2_1.md). Implementation status and next steps are maintained in [`nicejourney/docs/IMPLEMENTATION_STATE.md`](nicejourney/docs/IMPLEMENTATION_STATE.md) and [`nicejourney/docs/NEXT_DEVELOPMENT_SEQUENCE.md`](nicejourney/docs/NEXT_DEVELOPMENT_SEQUENCE.md).

The project contains **PLAYTEST** balance and placeholder resources; a passing code test does not mean production values, artwork, hardware or manual gameplay fairness are approved. The editor-authored resources are the source of current playtest numbers.

For the existing Godot reference test suite, from the Godot project directory run `./tools/reference_validation.ps1` in PowerShell. This runs editor and gameplay validation, not release exports.
